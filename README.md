# Jarvis — Python-Based AI Assistant

A personal AI assistant built with Python that combines a locally running Large Language Model (LLM), speech recognition, and automation tools.

## Features

- **Local LLM integration:** Uses Ollama with the Qwen3:4B model for AI-generated responses.
- **Speech recognition:** Uses Faster Whisper to process voice input.
- **Browser automation:** Supports browser-related tools and automation.
- **Modular architecture:** Separates core logic, language models, memory, speech, and tools into dedicated modules.
- **Memory:** Includes a dedicated memory module; supported capabilities depend on the current implementation.

## Tech Stack

- Python
- Ollama
- Qwen3:4B
- Faster Whisper
- Git and GitHub

## Project Status

In active development. Features and integrations are being improved incrementally.

## Getting Started

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in `requirements.txt`.
4. Install and configure Ollama and the required model.
5. Configure any required settings or environment variables.
6. Run the project's main entry point.

Refer to the project files for the exact configuration and startup commands.
